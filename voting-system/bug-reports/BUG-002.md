# BUG-002 — Special characters accepted in Full Name field

**Date:** June 2026  
**Reported by:** Marion Tamnai  
**Severity:** Low  
**Status:** Open  

## Environment
- Browser: Chrome
- OS: macOS
- URL: https://jkuat-online-voting-sysstem.netlify.app/
  
## Description
The Full Name field on the Add Student form accepts 
special characters and numbers. A student's full 
name should only contain letters and spaces.

## Steps to Reproduce
1. Login as admin
2. Go to Add Student page
3. In Full Name field type: Marion@#$%123
4. Fill in remaining fields normally
5. Click Add Student

## Expected Result
A validation error should appear:
"Full name should only contain letters and spaces"

## Actual Result
The form accepts the invalid name without 
any validation error.

## Severity Explanation
Low — does not break the system but could 
cause data quality issues in the student 
database and display problems elsewhere.
