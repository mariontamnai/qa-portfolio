# BUG-001 — Server error on short password input

**Date:** June 2026  
**Reported by:** Marion Tamnai  
**Severity:** High  
**Status:** Open  

## Environment
- Browser: Chrome
- OS: macOS
- URL: https://jkuat-online-voting-sysstem.netlify.app/

## Description
When admin attempts to add a student with a 
password shorter than the minimum required length, 
the system returns a server error instead of a 
friendly validation message.

## Steps to Reproduce
1. Login as admin
2. Go to Add Student page
3. Fill in Full Name, Year, Email, Registration 
   Number, Course
4. Enter a 1 character password e.g. "1"
5. Capture face
6. Click Add Student

## Expected Result
A validation message should appear e.g. 
"Password must be at least 8 characters" 
before the form is submitted to the server.

## Actual Result
A server error is returned. No friendly 
error message is shown to the user.

## Severity Explanation
High — server errors expose backend information 
and indicate missing frontend validation. 
Could affect system stability.
