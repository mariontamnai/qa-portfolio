# BUG-003 — Sensitive fields exposed in Get All Students API

**Date:** June 2026  
**Reported by:** Marion Tamnai  
**Severity:** Medium  
**Status:** Open  

## Environment
- Tool: Postman
- Endpoint: GET /api/admin/students

## Description
The Get All Students endpoint returns sensitive fields 
that should not be exposed in the API response.

## Steps to Reproduce
1. Login as admin
2. Send GET request to /api/admin/students
3. Inspect the response body

## Expected Result
Response should only return safe student fields:
fullName, regNumber, course, year, hasVoted

## Actual Result
Response exposes sensitive fields:
- resetPasswordToken
- resetPasswordExpiry  
- votingToken

## Severity Explanation
Medium — these fields are currently null but if 
populated they could expose sensitive reset tokens 
to anyone with admin access.
